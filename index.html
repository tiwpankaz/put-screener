Lightweight design — only 3 API calls per refresh: (1) Polygon screener endpoint — returns pre-filtered stocks under $30 with high volume in one call. (2) Batch snapshot — fetches prices + day data for all matched tickers in one call. (3) Options expiry calendar — fetches all expiry dates for next 90 days from SPY options in one call. IV is estimated from each stock's intraday range and daily return. Premium uses Black-Scholes at 8% OTM strike. Stocks with day change below −15% are excluded as likely sell signals. Always verify on your broker before trading. Not financial advice.
